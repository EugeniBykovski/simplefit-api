# Sponsor & Admin — API contract matrix (SF-107)

**Status: PROPOSED. No endpoint exists. Not in OpenAPI, no generated client.** Each implementing
task adds its operations with `operation_id`, the error envelope and committed OpenAPI.

## Conventions

| Topic | Rule |
| --- | --- |
| Prefix | `/api/v1`. Viewer's own under `/me`. Organization under `/sponsor-organizations/{sponsor_id}`, the id a lookup key checked on every request (as D-G23). Operator under `/admin` |
| Cache | `no-store` (the `:authenticated` pipeline) |
| Optimistic writes | `expected_revision`; stale → 409 `revision_conflict` |
| Idempotency | Applicant writes: `client_request_id`. Operator writes: `operation_id`, generated by the client. A repeat returns the first answer |
| Sponsor errors | 401 unauthenticated. 404 not a member, or unknown. 403 member without permission. 409 state. 422 validation. 429 limited |
| Operator errors | 401 unauthenticated. **404 for a non-operator on every `/admin` path**, indistinguishable from an unknown route. 403 `step_up_required` for an operator below the assurance level. 403 `forbidden` for an operator without that permission. 409 state or `conflict_of_interest` |
| Writes by operators | Authority asked, row locks taken, authority asked again, conflict check, transition, audit, in one transaction |

**Columns:** *R* = rate limit (per user unless stated). *Audit* A = application event, O = organization
event, AU = `operator_audit_events`.

## Sponsor: applicant

Actor: signed-in user with completed registration. Scope: own application only.

| Operation | Method and route | Request | Response | Transition | Idempotent | R | Audit |
| --- | --- | --- | --- | --- | --- | --- | --- |
| `getMySponsorApplication` | `GET /me/sponsor-application` | — | `SponsorApplication` (current or latest), or 404 | — | Yes | Standard | — |
| `listMySponsorApplications` | `GET /me/sponsor-applications` | cursor | Summaries, including terminal | — | Yes | Standard | — |
| `createSponsorApplication` | `POST /me/sponsor-application` | `client_request_id` | `SponsorApplication` | → `draft` | Key | 5/day | A |
| `updateSponsorApplication` | `PATCH /me/sponsor-application` | Partial answers, `expected_revision` | `SponsorApplication` | Edit in `draft`, `changes_requested` | Revision | 120/hour | — |
| `discardSponsorApplication` | `DELETE /me/sponsor-application` | `expected_revision` | 204 | `draft` → deleted | Yes | Standard | A |
| `presignSponsorApplicationFile` | `POST /me/sponsor-application/files` | Purpose, type, size, sha256 | Upload URL, `file_id` | — | Key | 30/hour | — |
| `completeSponsorApplicationFile` | `POST /me/sponsor-application/files/{file_id}/complete` | — | File, `scan_status` | — | Yes | Standard | — |
| `deleteSponsorApplicationFile` | `DELETE /me/sponsor-application/files/{file_id}` | — | 204 | Only while editable, and if not in a submitted revision | Yes | Standard | — |
| `submitSponsorApplication` | `POST /me/sponsor-application/submit` | `expected_revision`, `declaration_version`, `client_request_id` | `SponsorApplication` | `draft` or `changes_requested` → `submitted` | Key | 10/day | A |
| `withdrawSponsorApplication` | `POST /me/sponsor-application/withdraw` | `client_request_id` | `SponsorApplication` | Non-terminal → `withdrawn` | Yes | Standard | A |

**`SponsorApplication` DTO:** id, status, revision, answers, files (no storage keys), `editable`,
`missing_fields`, submitted and decided timestamps, the latest message to the applicant, and
`sponsor_id` once approved. **Never:** assignee, internal notes, reviewer identity, risk or scores.

| Errors | Code |
| --- | --- |
| Registration incomplete | 409 `account_registration_required` |
| A current application exists | 409 `application_exists` |
| Fields missing | 422 with `fields` |
| File not scanned clean | 409 `file_not_ready` |
| Not editable | 409 `application_not_editable` |
| Cooldown active, if approved | 409 `reapply_not_available` |

## Not proposed

Any endpoint that lists private coaching, health, message or gym member data. Any "act as user".
Any endpoint accepting an operator id, email or authority value from the client. Any grant by
`/me`. Any campaign, invoice, analytics or CRM endpoint.
